From briefing room to signed debrief in one session.

SimSynch follows the actual rhythm of a simulator check — not an abstraction of it. Every step maps directly to what an instructor does in the bay.

A
Build the session on a visual board
The Session Board replaces the slot table with a two-day kanban: exercises are cards, days are columns, phases are swimlanes. Drag to reorder, drop into a different lane or day, and the sequence updates instantly — with a List view always one click away for anyone who prefers the table. SimSynch draws from a 125-event A320 scenario bank and attaches the right Observable Behaviours automatically via a three-tier OB matching engine.
Session Board · Board / List toggle · 125 scenarios
B
Upload a programme — inject, select, arrange, save
Upload an FCOM abnormal procedures document, EBT lesson plan, or LPC/OPC Instructor Guide. SimSynch auto-detects the format and matches training events against the exercise library. Select which exercises to run, then arrange them on a two-day visual board — drag between Day 1 and Day 2, set crew role per exercise — before anything is saved.
Inject PDF → Select → Arrange Board → Save
C
Grade in real time
The ORCA grading view shows one Observable Behaviour per row. Mark it observed, select a grade from 1–5, add a note. Every entry saves immediately — no batch submit, no lost data if the session runs long. The controlling grade (lowest observed OB) updates live.
Auto-save · Controlling grade · MAL tracking
D
Debrief with evidence
The Session Debrief shows a live competency radar, bar chart, and Venn diagram built from the graded OBs. Focus areas (below-MAL competencies) are highlighted automatically. Save the debrief to mark the session Complete and lock the record.
Competency radar · PASS / RETRAIN verdict
